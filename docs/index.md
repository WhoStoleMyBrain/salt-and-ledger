# Salt & Ledger

Build a maritime company in a finite, deterministic economy. See the seeded map, draft four mandatory Grand Commission objectives, and connect real production and household demand with physical ships. Sandbox uses the same current rules without a deadline.

Start with the [player guide](PLAYER_GUIDE.md), [Grand Commission](GRAND_COMMISSION.md), [Harbor](HARBOR.md) and [cargo itineraries](AUTOMATION.md). Browse the generated [encyclopedia](reference/index.md) for the same content and mechanics help available offline in the game.

For development, read [architecture](ARCHITECTURE.md), [mechanics](MECHANICS.md), [Unity setup](UNITY.md), [save policy](SAVES.md) and [current verification](REPOSITORY-CLEANUP.md). Current economic experiments report both productive outcomes and shortages; they are evidence, not a guarantee of equilibrium.
