# Current economic experiments

Current reports use generator4, circulation1, storage2, itinerary1, schema9 and compact report format4. They execute ordinary commands without repairing cash, stock, welfare or policy outcomes. Every commit audits physical flows, FIFO and both money boundaries. A Grand Commission victory certifies its four goals, not perpetual prosperity.

## Reproduce

```text
dotnet run --project samples/SaltAndLedger.Demo -c Release -- data/content.json --expanding-economy --check
dotnet run --project samples/SaltAndLedger.Demo -c Release -- data/content.json --economic-circulation --check
dotnet run --project samples/SaltAndLedger.Demo -c Release -- data/content.json --grand-commission --check
dotnet run --project samples/SaltAndLedger.Demo -c Release -- data/content.json --world-generation --check
dotnet run --project samples/SaltAndLedger.Demo -c Release -- data/content.json --npc-companies --check
```

The [normal report](experiments/expanding-economy-results.json) contains 29 comparisons: seeds42/99, thirteen prescribed policies through180 days, two additional charter cases and one Coverage/Ascension1 network case. This is an experiment horizon, independent of the new720-day default Commission deadline. Reversed setup and Turkish-culture replay must match exactly. No machine timing, path or timestamp enters report bytes.

Policies cover idle, one-way imports, complementary trade, separated industry/overbuilding, finite external exports and controls, physical Silver/Mint and controls, circulation, and two/three-ship networks. Autonomous NPC companies also use the ordinary market and industrial route executors; prescribed player market/industrial policies remain research controls; player route editing uses cargo itineraries. All facilities now resolve actual recipe eligibility. Mills ship Flour to distinct Bakery towns; shipbuilding imports any needed real Planks to the generated shipyard before ordering. These are ordinary paid shipments, not added test inventory.

The [reinvestment report](experiments/expanding-reinvestment-results.json) contains12 cases and4380 primary world-days. The [circulation report](experiments/economic-circulation-results.json) contains64 fiscal-arm worlds and16 controls, covering29200 primary world-days. Combined-treatment checkpoints restore exact schema9 saves and compare ordinary continuation. All studies preserve finite accounts, current fees, recipe quantities and actual warehouse price limits.

## Interpreting the results

Structural supply does not promise production or profitability. A Bakery with available distant input sources can still fail because its warehouse price limit prevents acquiring a full batch, a voyage has not delivered cargo, or payroll cannot be funded. New towns, routes and NPC populations change these outcomes; four-town numerical comparisons from earlier tasks remain historical and must not be treated as current predictions.

The [Task3.3 verification record](TASK-3.3-VERIFICATION.md) records the current autonomous-company checks; the Task3.1 record remains historical. Reports retain complete per-town stock, household/market cash, production, consumption and route observations in compact JSON. Company Value includes reference capital and holdings, not realizable sale proceeds. Long-horizon deprivation, depleted budgets and unprofitable policies remain possible and are reported without economic rescue.

Optional `--deep` expands the bounded seed matrix. Optional `--reinvestment --check` checks its separate artifact. These experiments establish reproducibility and measured mechanisms; they do not establish universal economic recovery, every Commission combination's profitability, or Unity visual playability.
